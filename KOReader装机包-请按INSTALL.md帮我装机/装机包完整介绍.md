## 装完你会拥有一台怎样的 Kindle

躺在被窝里就能刷**微信读书**和**番茄小说**；想看什么书，
直接在 Kindle 上搜 **Z-Library** 免费下载，一次都不用开电脑；
碰到不认识的词一点就查（12 部词典任选），划一句话就能问 **AI 伴读**
（词义、翻译、句子解析张口就来）；翻页带顺滑动画（过去只有新机型才有），
读书全程可以不被闪屏打断；**传书再也不用数据线**——
同一 WiFi 下浏览器里一拖就进书库，比原版方便得多；
丰富的锁屏以及精致的阅读小票。
一句话：**一台比原装 Kindle 好用得多、越用越顺手的阅读神器。**
（其中微信读书、番茄小说、AI 伴读、翻页动画、锁屏壁纸为选装，
装机时 AI 会逐项问你，讲清楚功能后由你勾选。）

## 一、这个装机包是什么

这是一套在 Kindle 上调教得非常好用的 **KOReader 完整环境**，
打包成一键装机包交给 AI 助手（WorkBuddy）自动安装。

**KOReader** 是 Kindle 上免费开源的阅读器，比原装系统好用很多：
词典、字体、排版、手势、插件都能自定义。

**已经装过官方 KOReader 的人**：装机时会推荐你换成本包的**改良版**——
同样基于官方版本，但删掉了用不到的菜单和插件（界面清爽、省内存）、
修复了官方插件的已知 BUG（保活休眠、词典加生词本、多音字注音等）、
内置了三枚性能探针（出问题自动留证据、可远程排查）。覆盖安装，
书、生词本、词典都不会丢；不想换也可以在现有版本上叠加安装。

这个包能一次给你装上：

| 能力 | 说明 |
|---|---|
| 微信读书（选装） | 在 KOReader 里读微信读书的书、同步进度 |
| 番茄小说（选装） | 在 KOReader 里直接读番茄小说：同步书架/进度、段评、离线缓存 |
| 在线搜书下载 | Z-Library 插件，设备上直接搜书下载 |
| 查词 | 12 部词典任选（汉语/成语/古文/诗词/牛津双解……） |
| AI 伴读（选装） | 划词问 AI：词义、翻译、句子解析 |
| 完整手势 | 双击切夜间模式、四边滑动调亮度、捏合全刷等（见 §五） |
| 界面美化（选装） | 卡片式书库主页 + 6 款中文字体 |
| 锁屏壁纸（选装） | 休眠锁屏显示壁纸 + 书籍信息卡 |
| 阅读小票 | 锁屏显示像小票一样的阅读进度单 |
| 无线传书 | 电脑浏览器拖文件就能传书，不用插线 |
| 作者同款设置（可选） | 装机收尾时可一键同步作者实测调好的全套配置（排版/页眉/手势/壁纸等，不含任何账号和个人数据） |
| 售后保障 | 性能探针自动记录卡顿/崩溃元凶到日志，出问题 AI 远程排查 |

**安全放心**：包里不含任何账号、密码、密钥和个人阅读数据；
装机全程自动备份到 `backup/` 目录，可整体回滚（`文档/rollback.md`）。

## 二、怎么用（3 步，实际要动手的只有插根线）

1. **确认 Kindle 已越狱、装好 KUAL**（没越狱先解决越狱，这个包管不了这步）。
2. **用 USB 线把 Kindle 插到电脑上**：Kindle 弹窗选「传输文件」；
   KOReader 开着的话先在菜单里退出。不用复制任何东西——
   连 KOReader 都没装也没关系，AI 会带你装。
3. **把整个文件夹拖进 AI 助手对话窗口**，发送这句话：

   > 请按 INSTALL.md 帮我装机

   AI 会自动装机：它自己通过 USB 把所有文件写进 Kindle，中途只会问你
   几个问题（见 §四），照着回答就行；最后弹出 USB、重启一次 KOReader。

装完 AI 还会问 4 件收尾小事：Z-Library 账号（没有会教注册）、
AI 密钥（选装了 AI 伴读才有）、要不要把无线传书网址加入浏览器收藏夹、
要不要在电脑装 Calibre（免费书库管理/格式转换软件）。

### 只想装其中一部分？（组件编号 1–14）

如果设备上已经装过别的插件、只想要本包里的部分组件，发送装机指令时
**直接带上编号或名字**，比如：

> 请按 INSTALL.md 帮我装机，只装 1、5、8、14 号

编号对照（与《使用说明.txt》《README.md》一致；执行规则见 INSTALL.md §1.7）：

| 编号 | 组件 | 状态 | 编号 | 组件 | 状态 |
|---|---|---|---|---|---|
| 1 | Z-Library 搜书下载 | 必装 | 8 | 锁屏壁纸 | 询问 |
| 2 | 12 部词典 | 必装 | 9 | 生僻字注音 | 询问 |
| 3 | 完整手势 | 必装 | 10 | AI 伴读 | 询问 |
| 4 | 阅读小票 | 必装 | 11 | 翻页动画（仅新机型） | 询问 |
| 5 | 诊断探针 | 必装 | 12 | 蓝牙/外接键盘（含 SSH） | 询问 |
| 6 | 拼音输入 | 必装 | 13 | 觅阅·微信读书 | 询问 |
| 7 | 界面美化 | 询问 | 14 | 番茄阅读 | 询问 |

未指定的组件一律跳过、不再询问；直接说名字（"只装锁屏壁纸和番茄"）也行。
小建议：5 号诊断探针尽量留着——以后出问题，AI 靠它远程看报告排查。

⚠ 小提醒：装机过程中别让 Kindle 睡着（插着充电线也会睡！

## 五、预设手势一览（不满意可以改）

**阅读时**：

| 手势 | 作用 |
|---|---|
| 双击屏幕左侧 | 切换夜间模式 |
| 双击屏幕右侧 | 显示菜单 |
| 长按左下角 | 目录 |
| 长按右下角 | 快速查看盒（阅读统计等） |
| 屏幕左/右边缘向上滑 | 调亮背光 |
| 屏幕左/右边缘向下滑 | 调暗背光 |
| 捏合（双指向内） | 全屏刷新（清残影） |
| 张开（双指向外） | 回 simpleUI 主页（书库界面为 Z-Library 搜索） |

**多向滑动（multiswipe，先→后连续划）**：

| 滑动方向 | 作用 |
|---|---|
| 右→上 | 最近阅读历史 |
| 右→下 | 跳页 |
| 右→左 | 最近书签 |
| 右→左→右 | 收藏夹 |
| 右→下→左→上 | 全屏刷新 |
| 上→右 | 目录 |
| 上→左 | 书签列表 |
| 上→下→上 | 上一章 |
| 下→上 | 快速翻页（翻页浏览） |
| 下→上→下 | 下一章 |
| 下→左 | 背光亮度调节面板 |
| 下→右 | PDF 重排开关 |
| 下→右→上 / 下→右→上→下 | 缩放至内容高度 / 页面高度 |
| 上→右→左 / 上→右→左→右 | 缩放至内容宽度 / 页面宽度 |
| 左→右 | 回到上次跳转前的位置 |
| 左→右→左 | 打开上一本书 |
| 左→上 | 书本状态 |
| 左→下 | 返回 |
| 右下斜→左下斜 | 跟随最近的链接 |
| 右下斜→左下斜→左上斜 | 打开 WiFi |
| 右下斜→左下斜→左上斜→再左下斜 | 关闭 WiFi |
| 西北斜→西南斜→西北斜 | WiFi 开关切换 |

**书库界面额外**：上→下 = 返回上一级目录；上→左 = 文件夹快捷方式；
右→下 = 跳转；其余与阅读时相同。

**对手势不满意怎么改**：

- 自己改：KOReader 顶部菜单（点屏幕上方）→ 工具 → 手势（Gesture Manager），
  里面每个手势都能重新指定或关掉；
- 或直接让 AI 助手帮你改（说一句「我想把双击左边改成翻页」即可，
  设备连着就能远程改 `koreader/settings/gestures.lua`）。

## 六、壁纸怎么换

**锁屏壁纸**（装了锁屏壁纸插件的）：

- 位置：USB 连电脑后，Kindle 磁盘里的
  `koreader/plugins/customisablesleepscreen.koplugin/wallpapers/`
- 里面分三个文件夹：`catppuccin/`（6 款风景）、`nord/`（6 款风景）、
  `custom/`（装机时选的猫猫探头 / 撕纸就在这里）
- 换成自己的：把图片（PNG，竖屏为佳）放进 `custom/` 文件夹，
  再到 KOReader 菜单 → 锁屏壁纸设置里选它即可

**主页壁纸**（装了界面美化 simpleUI 的）：

- 位置：USB 连电脑后，Kindle 磁盘里的
  `koreader/settings/simpleui/sui_wallpapers/`
- 把自己的图片（PNG）放进这个文件夹（和现有 wallpaper1.png 放一起），
  然后在 simpleUI 主页的设置里选它

两个文件夹也都可以通过无线传书浏览器（FilebrowserPlus 的网页地址）
直接上传图片，不必插 USB。

## 七、遇到问题怎么办

使用中出**任何**问题——崩溃退出、卡死、翻页或手势失灵、查词没结果、
插件打不开、AI 没反应、Z-Library 搜不到书、电脑连不上传书网址、
锁屏壁纸不显示、想改字体/壁纸/任何设置不会弄——只要
① Kindle 开着 KOReader（无线传书默认开机自启、运行期间常开）和电脑同 WiFi，
或 ② USB 插着电脑，都可以直接问 AI 助手：它会读取探针日志
`koreader/crash.log` 远程诊断，边看边修。
设备连得上，问题就问得出。

以后还需要什么别的插件，也可以直接告诉 AI 助手（WorkBuddy），
它能帮你从网上找到并直接装进 Kindle，不用自己折腾。
