安装
把本目录整体复制到 KOReader 的插件目录:

设备:koreader/plugins/pinyin.koplugin/

或 KOReader 的 plugins/ 目录(与官方插件同级)

重启 KOReader。

打开一本中文书 → 顶部菜单 → 「工具」→「生僻字注音」。

点「开启拼音标注」即可。

插件目录结构(直接拷到 KOReader 即可用):

koreader/plugins/pinyin.koplugin/
├── main.lua                # 插件主体(无需改动)
├── pinyin_data.lua         # 拼音+排名数据(已生成, 开箱即用; 默认 8105 全量)
├── phrase_data.lua         # 词组数据(约 8600 词组, 多音字辨音/生词本词组读音用)
├── polyphone_index.lua     # 多音字索引(694 字, 启动载入)
├── default_fix.lua         # 默认读音修正(430 字)
├── config.lua             # 高级配置(调试日志/诊断信息开关, 默认均关闭)
└── README.md

生词本联动(可选):需另装 KOReader 官方"生词本"(vocabbuilder)插件;查词时可点词典里的按钮把词加入生词本。

使用
在「生僻字注音」子菜单中:

菜单项	作用
开启/关闭拼音标注	总开关
标注等级	1–5,越高注音越多(默认 2 = 生僻字);各级含义见下
生词本注音: 开/关	生词本里的词整词出现才注音;单字入本则该字每次出现都注
拼音字号	8–28(默认 12,首次使用请先调到 ≥ 26),太小会显示不全/挤压
颜色: 深灰	切换黑色 / 深灰(更贴近 Kindle 提示色)
调试日志 (写 KOReader 日志)	默认隐藏;在 config.lua 把 enable_debug_log 设为 true 并重启后才出现
查看诊断信息	默认隐藏;在 config.lua 把 show_diagnostics 设为 true 并重启后才出现;开启后可直接查看本页注音统计
关于 / 帮助	说明

多音字词组辨音:始终开启,不设开关(纯查表,不影响翻页速度),如"银行"注 háng、"行走"注 xíng。

标注等级说明 (1–5)
「标注等级」决定给多生僻的字注音:rank 越小越常用,rank 越大越生僻;只有 rank 大于该等级阈值(见下)的字才被画上拼音。可在「生僻字注音」子菜单里用 ↑/↓ 调节。

等级	含义	rank 阈值
1	最生僻字	rank > 7000
2(默认)	生僻字	rank > 6250
3	较生僻字	rank > 5500
4	生字较多	rank > 4750
5	生字注音(覆盖面最宽)	rank > 4000
阈值与代码 LEVEL_THRESHOLD = {7000,6250,5500,4750,4000} 完全一致,默认等级 2。 想"只给最难的字注音"就往低调(1);想覆盖更宽就调到 5。
